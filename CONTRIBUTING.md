# Contributing to VeSpA

Thank you for your interest in contributing to VeSpA!

## How to Contribute

1. Fork the repository
2. Create a feature branch (`git checkout -b feature/your-feature`)
3. Commit your changes
4. Open a pull request against `main`

## Reporting Issues

Please use the [GitHub Issues](../../issues) page to report bugs or request features. Include:
- QuPath version
- Java version
- Operating system
- Steps to reproduce

## Code Style

This project follows standard Java conventions. Ensure your code compiles cleanly with Gradle before submitting a PR.
